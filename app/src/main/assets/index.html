📲 내 휴대폰에 설치(.apk)하는 2가지 방법

채팅창에 함께 제공된 안드로이드 프로젝트 압축파일(.zip) 안에 실제 만보기 센서·갈맷길 GPS 70% 인증·자동걷기 기계 차단 코드와 자동 빌드기가 모두 들어 있습니다.

가장 쉬운 방법 (1분 완성)

방법 1. 지금 바로 휴대폰 홈 화면에 앱으로 설치

  1. 안드로이드 폰 크롬(Chrome)이나 삼성 인터넷으로 이 앱 파일을 엽니다.
  2. 우측 상단 메뉴(점 3개 ⋮) → [홈 화면에 추가] 또는 [앱 설치]를 누릅니다.
  3. 바탕화면에 '갈맷길 백세만보' 아이콘이 생성되어 일반 앱처럼 전체 화면으로 작동합니다!
정식 .apk 설치파일 추출 (프로그램 설치 불필요)

방법 2. 무료 자동 빌드기로 진짜 .apk 파일 받기

컴퓨터에 무거운 개발 프로그램을 깔지 않아도, 함께 드린 busan_galmaetgil_android_project.zip 파일을 무료 GitHub에 올리면 서버가 대신 .apk 파일을 만들어 줍니다.

  1. 채팅창에서 busan_galmaetgil_android_project.zip을 다운받아 압축을 풉니다.
  2. 무료 사이트 github.com 로그인 후 새 저장소(New Repository)를 만듭니다.
  3. 압축 푼 파일들을 마우스로 끌어다 업로드(Upload files)하고 저장(Commit)합니다.
  4. 상단 [Actions] 탭을 누르면 3분 뒤 완성된 Galmaetgil-Pedometer-APK 설치 파일을 바로 다운로드할 수 있습니다!

① 시니어 맞춤 큰 글씨 & 안드로이드 TTS 음성

MainActivity.kt에서 안드로이드 내장 음성합성(TextToSpeech)과 하드웨어 만보기 센서(TYPE_STEP_COUNTER)를 실시간 연결합니다.

② 갈맷길 GPX 좌표 70% 스탬프 판별

GalmaetgilGpsTracker.kt가 부산 갈맷길 구간별 체크포인트 반경 50m 통과 여부를 계산해 70% 이상 걸으면 자동으로 도장을 찍어줍니다.

③ 자동걷기 기계(흔들기) 3중 차단 필터

AntiCheatDetector.kt가 1) 무휴식 정속 흔들기(보폭 주기 분산 < 2.5%), 2) 새벽 01~05시 비정상 폭증, 3) GPS 미이동 제자리 흔들기를 걸러내 공정 순위를 지킵니다.
